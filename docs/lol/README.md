# Base de conhecimento League of Legends (LoL)

Esta pasta reúne a documentação de referência sobre o League of Legends e a integração da API com os serviços da Riot Games, Data Dragon e Community Dragon.

## Índice da documentação

- [`patches-e-versoes.md`](patches-e-versoes.md) — Cadência de patches, ciclo de publicação do Data Dragon, gatilho `versions.json` e o mecanismo de troca automática de patch da API.
- [`data-dragon-e-community-dragon.md`](data-dragon-e-community-dragon.md) — Dicionários e imagens do Data Dragon (CDN public), estatísticas do Community Dragon, locales e tratamento de chromas/skins.
- [`riot-api-roteamento-e-limites.md`](riot-api-roteamento-e-limites.md) — Plataformas (hosts locais) vs. regiões de roteamento, autenticação por `X-Riot-Token`, dev keys, rate limits, `Retry-After` e tratamento de Riot ID.
- [`modos-de-jogo.md`](modos-de-jogo.md) — Arena (CHERRY/subteams), filas ranqueadas, ARAM e normales, com os impactos correspondentes na API.
